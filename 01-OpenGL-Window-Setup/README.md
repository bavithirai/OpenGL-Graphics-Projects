# OpenGL Window Setup

## Overview

This project marks the beginning of my OpenGL learning journey using Java and JOGL. It focuses on setting up the basic rendering environment that serves as the foundation for the graphics, animation, and transformation projects that follow.

## What I Built

- Created an OpenGL-enabled application window using JOGL
- Configured a `GLCanvas` for rendering
- Set up an 800 × 800 graphics window
- Implemented the basic JOGL rendering lifecycle
- Established a reusable foundation for future OpenGL projects

## Technologies

- Java
- JOGL (Java OpenGL)
- OpenGL

## What I Learned
Through this project, I learned how a Java application connects to OpenGL through JOGL and how the rendering window, canvas, and OpenGL context are initialized before drawing graphics.
This project serves as the starting point for progressively exploring shaders, vertex rendering, animation, transformations, and more advanced graphics concepts.
